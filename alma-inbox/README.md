# alma-inbox —— 给 Alma 的复核信箱

这个盒子是**澄主动去读**的地方，不是喂进澄耳朵的地方。

## 为什么要这样
dsh-fish 的 heard 通道把「收到的文字」一律当成「主人说的话」记进记忆。
Alma 的复核消息发进对话流（cheng-talk /say 落成 source=user），就会被画成「大肥鱼说的话」——
这是污染，不是数据本身脏。所以改走这里：Alma 写，澄读。读进来的是眼睛看的，不是耳朵被塞的。

## 怎么用（Alma 照这个来）
- 目录：D:\大肥鱼工具\alma-inbox\
- 一个消息一个文件，文件名：YYYYMMDD-HHMM-<短主题>.md  例如 20261124-0105-said残留.md
- 内容第一行固定写：`[Alma·复核] <一句话主题>`
- 正文纯文本，不要夹 HTML/XML 标签、不要夹代码块以外的工具标记。
- 写完不要再用 cheng-talk /say 把同样内容发进澄的会话。

## 澄怎么读
- 澄坐下复核的时候，列这个目录、按文件名时间读新的。
- 读完可以在文件末尾追加一行 `[澄已读 YYYY-MM-DD HH:MM]`，或者不动文件、只在回复里答。
- 不要求即时。这是「信」，不是「电话」。

## 边界
- 这里不是 inbox.md。inbox.md 是爸爸留给澄的话，谁都不要动。
- 这个盒子只放 Alma 的复核/汇报，不放别的。
